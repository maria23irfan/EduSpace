# 📚 EduSpace

**EduSpace** is a modern educational website designed to make learning simple, engaging, and accessible for students. It brings useful subjects, study resources, and educational content together in one organized platform.

## ✨ Features

* 📖 Subject-based learning sections
* 🔍 Easy and simple navigation
* 📝 Study and revision resources
* 💡 Educational content and useful resources
* 🎯 Student-focused design
* 📱 Responsive layout for different screen sizes
* 🎨 Modern and clean user interface
* ⚡ Smooth interactions and animations

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layouts, animations, and responsive design
* **JavaScript** – Interactive features and website functionality

## 🎓 Purpose

EduSpace was created to provide students with a comfortable digital environment where they can **learn, explore, discover resources, and improve their knowledge**.

The website focuses on combining useful educational content with an attractive and easy-to-use interface.

## 🚀 Getting Started

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the EduSpace website.

No additional installation is required.
